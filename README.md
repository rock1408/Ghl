# GoHighLevel Affiliate Landing Page

A modern, high-converting single-page landing page promoting GoHighLevel (GHL).

## Deploying to Vercel

This repository is pre-configured for 1-click deployment on [Vercel](https://vercel.com):

1. Push this repository to your **GitHub** account.
2. Go to **[vercel.com/new](https://vercel.com/new)** and import your GitHub repository.
3. Vercel will automatically detect the settings from `vercel.json`:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
4. Click **Deploy**. Your site will be live in seconds.

## Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
